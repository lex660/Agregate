## Как проверить новую версию локально

```
git worktree add /tmp/wt-rebuild origin/rebuild-eleventy
cd /tmp/wt-rebuild
npm ci
npm test          # 26 тестов
npm run build     # сборка в _site
npm run check     # проверка ссылок, CSP, дисклеймера, sitemap
npm start         # http://localhost:8080
```
