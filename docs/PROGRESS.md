## CI и автоматизация

| Workflow | Когда | Что делает |
|---|---|---|
| `ci.yml` | Каждый PR и push не в `main` | Линтер, тесты, сборка, `npm run check` |
| `deploy.yml` | Push в `main`, вручную | То же + публикация: Yandex Object Storage, если задана переменная `YC_BUCKET`, иначе GitHub Pages |
| `reconcile.yml` | Каждый день 09:17 МСК, вручную | Сверка калькуляторов Tasnim, КупиТак, LaRiba, Ватан, Al-Baraka с `data/tariffs.json`. Расхождение или недоступный сайт → issue с меткой `data-drift`; совпало → issue закрывается |
| Dependabot | Понедельник 06:00 МСК | npm и GitHub Actions; minor/patch одним PR |

Не проверено: доступны ли сайты компаний с серверов GitHub (из среды Claude закрыты).
Если первый запуск `reconcile.yml` откроет issue с «не удалось прочитать» по всем
компаниям — вероятно, сайты не пускают зарубежные IP; тогда сверку оставляем
в Yandex Cloud Function (`functions/reconcile`, тот же код).

## Как проверить новую версию локально

```
git worktree add /tmp/wt-relaunch origin/release/relaunch
cd /tmp/wt-relaunch
npm ci
npm run lint      # ESLint
npm test          # 35 тестов
npm run build     # сборка в _site
npm run check     # ссылки, CSP, дисклеймер, согласие на cookie, политика, sitemap
npm run reconcile # сверка с сайтами компаний (нужен доступ к ним)
npm start         # http://localhost:8080
```
