# Агрегатор исламской рассрочки — как это устроено и как запустить

## Что изменилось по сравнению со старой версией
- **Нет бэкенда.** Расчёт идёт прямо в браузере по `data/tariffs.json`. Нечему «упасть» ночью — сайт работает, даже если сайты компаний недоступны.
- **Cloudflare Worker больше не нужен.** У него открыта админка без пароля (см. `claude/worker-audit.md` в проекте) — после запуска новой версии его нужно **удалить** в панели Cloudflare.
- **Тарифы берутся из публичных калькуляторов компаний** с датой проверки и источником. Цифр «на глаз» нет: если компания не публикует ставки, она показывается с пометкой «условия уточняются».
- **Взнос пользователя учитывается.** Если он ниже минимума компании, карточка не исчезает, а пишет «нужен взнос от N ₽».
- **Переход на сайт компании** — с UTM-метками (компания увидит, что клиент пришёл от вас) и кнопкой «Скопировать расчёт», чтобы вставить в анкету или WhatsApp.

## Структура
| Путь | Что там |
|---|---|
| `data/tariffs.json` | Компании и тарифы. Единственный источник истины. |
| `src/assets/js/calc.js` | Формулы расчёта (по одной на модель компании). |
| `src/assets/js/app.js` | Интерфейс калькулятора. |
| `src/*.njk` | Страницы: главная, регионы, компании, методика, реклама. |
| `src/_data/ads.json` | Баннеры. Реклама без рекламодателя и erid не показывается. |
| `tests/` | Тесты расчёта на эталонных примерах и тесты сверки. |
| `scripts/check-site.mjs` | Проверка перед релизом: ссылки, CSP, дисклеймер, sitemap, старый домен. |
| `functions/reconcile/` | Ежедневная сверка тарифов (Yandex Cloud Function → Telegram). |
| `.github/workflows/deploy.yml` | Тесты → сборка → публикация. |

## Команды
```
npm install
npm test          # тесты расчёта и сверки
npm run build     # сборка в папку _site
npm run check     # проверка собранного сайта
npm start         # локальный просмотр на http://localhost:8080
```

## Запуск — шаги для владельца
1. **Подключить GitHub к Claude** (claude.ai → Настройки → Коннекторы → GitHub), чтобы я мог сам открывать PR. Пока это не сделано — загрузите ветку вручную (см. ниже).
2. **Влить PR** `rebuild-eleventy` в `main`.
3. **Включить GitHub Pages:** репозиторий → Settings → Pages → Source: **GitHub Actions**. Через 1–2 минуты сайт откроется по адресу `https://lex660.github.io/Agregate/`. Это временный адрес.
4. **Домен.** `vsay-rassrochka.ru` не отвечает. Варианты: продлить его у регистратора (если ещё в периоде восстановления) или взять новый. Решение за вами.
5. **Yandex Object Storage** (основной хостинг, ~0,5–2 $/мес):
   - создать бакет с именем домена, включить «Хостинг сайта», главная `index.html`, ошибка `404.html`;
   - создать сервисный аккаунт с ролью `storage.editor` и статический ключ доступа;
   - в GitHub → Settings → Secrets and variables → Actions: секреты `YC_ACCESS_KEY_ID`, `YC_SECRET_ACCESS_KEY`; переменные `YC_BUCKET` (имя бакета) и `SITE_URL` (`https://ваш-домен.ru`);
   - HTTPS: сертификат Let's Encrypt в Certificate Manager и привязать к бакету.
   После этого каждый push в `main` публикует сайт в Object Storage, а GitHub Pages перестаёт обновляться (его можно выключить в Settings → Pages).
6. **Сверка тарифов:** создать Cloud Function (Node.js 22), загрузить папку `functions/reconcile`, точка входа `index.handler`, таймер `0 6 ? * * *` (09:00 МСК). Переменные: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (токен — через Lockbox). Бесплатный лимит функций это покрывает.
7. **Яндекс.Вебмастер:** добавить новый адрес, загрузить `sitemap.xml`. Файл подтверждения `yandex_49e44b65439ecbfe.html` уже лежит в корне.
8. **Удалить старый Cloudflare Worker** `islamic-installment-api`.

## Как обновить тарифы
1. Изменить `data/tariffs.json` в новой ветке: новые цифры + `verified_at` (дата) + `source` (откуда).
2. `npm test` — если меняются формулы, обновить эталонные примеры в `tests/calc.test.mjs`.
3. PR → после проверки влить в `main`.

## Добавить компанию
Нужно: юрлицо, ИНН, регионы, наценки по срокам, лимиты суммы/срока/взноса, письменное подтверждение и его дата, есть ли компания в реестре ЦБ (если есть — поле `cbr_registry`). Пока ставок нет — `"confirmation": "pending"`, и компания покажется без расчёта.

## Реклама
Баннер показывается, только если в `src/_data/ads.json` заполнены `advertiser` и `erid` (маркировка по ст. 18.1 ФЗ «О рекламе»). Баннеры Adab выключены до получения этих данных.
